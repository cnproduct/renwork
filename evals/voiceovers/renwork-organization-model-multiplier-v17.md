# Voiceover V17 — 组织级 RenCredit 模型倍率

平台超级管理员可以在组织的“模型与额度策略”中，为每个已发布模型设置该组织专属的 RenCredit 结算倍率。界面同时显示平台默认倍率、组织覆盖值和最终生效倍率；覆盖值留空时继承平台倍率，并可一键恢复继承。

组织倍率是平台管理员专属策略。组织 Owner 仍只管理模型白名单、默认模型、组织预算和成员额度，不能读取或修改组织倍率覆盖。普通成员目录只显示最终生效倍率，不暴露平台路由、密钥或内部计价信息。

保存倍率时记录操作者、组织、模型、原值、新值、时间和策略版本。普通倍率必须是大于零的有限值；零价只能通过独立的限时活动或超级管理员特批授权实现。

云端网关和受控的本地 OAuth / 本地运行时，在冻结、结算、失败释放和幂等重放时都使用同一个组织生效倍率。任务收据保留平台倍率、组织覆盖值、最终倍率、目录版本和组织计价策略版本，确保结算可审计且不会因后续改价而漂移。
