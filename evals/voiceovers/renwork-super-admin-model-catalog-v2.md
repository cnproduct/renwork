# RenWork 超级管理员模型目录 V2

1. 平台超级管理员进入 RenWork 后台，打开“模型与 RenCredit”；普通成员和企业管理员无法进入。
2. 首页先展示目录版本、供应商健康数、已发布模型数和普通用户可见模型数。
3. 超级管理员分别设置官方模型、企业自有 Key 和本地运行模型的 Token 计费策略；默认全部按实际 Token 扣 RenCredit。
4. 在供应商网关中配置 OpenRouter、OpenCode、直连厂商或自定义兼容接口，只填写服务端密钥引用，不在浏览器显示真实 Key。
5. 超级管理员测试已保存供应商连接，查看健康状态、HTTP 状态和延迟。
6. 在模型与路由中配置稳定 RenWork SKU、用户显示名称、能力档位、发布状态、上下文、展示倍率、实际计价倍率、五类 Token 单价、套餐、促销和路由优先级。
7. 用户预览只显示 RenWork 模型名、能力说明、倍率与计费模式，不显示第三方供应商、Base URL、密钥引用或上游模型 ID。
8. 点击“发布目录”后，服务端使用旧版本执行并发冲突保护，生成新目录版本；普通用户模型选择器读取新目录。
9. 实际任务按最终命中的路由和五类 Token 用量结算；失败释放预占，重复结算保持幂等。
