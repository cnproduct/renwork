# Voiceover V45 — 商业化闭环与超级管理员统一授权中心

平台超级管理员打开任意组织的“模型与额度策略”，先看到 Den 服务端供应商授权。没有有效授权时，该组织和成员既看不到对应模型，也不能通过推理接口调用它。

超级管理员可以把已在全局目录配置的服务端供应商授权给全组织或指定成员，并限制模型范围和到期时间。组织 Owner 和普通成员不能创建、测试、更新、撤销或读取供应商凭据。

模型最终权限由平台已发布目录、付费套餐或限时特批、组织模型白名单、成员模型白名单、有效供应商授权和 RenCredit 余额共同决定。任意一项不满足都必须拒绝。

成员发送模型请求时，Den 再次校验同一授权关系，然后执行 RenCredit 报价、冻结、上游调用和结算。上游失败、流中断或用户取消时释放冻结。客户端永远拿不到真实供应商 ID、上游模型 ID 或密钥。

个人 ChatGPT Plus/Pro OAuth 不得跨无关客户共享。组织共享模型只接入具备商业团队授权的服务端 API、企业方案或供应商明确允许的 Token Plan。

生产部署前先为存量组织建立明确授权，避免默认拒绝造成中断；测试覆盖无授权、过期授权、成员限制、跨租户、余额不足、失败释放和伪造模型请求。
