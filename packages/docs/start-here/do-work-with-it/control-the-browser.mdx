---
title: "Control the browser"
description: "How to use RenWork to automate the built-in browser"
---

Computer-use in RenWork currently works through the built-in RenWork Browser. It does not yet mean full desktop control of Ubuntu, macOS, or Windows apps.

RenWork can open pages, click, fill forms, read page content, and take screenshots inside that browser. If you connect to a remote RenWork server, the browser runs on that remote worker.

Today, the supported path is the first-party `RenWork Browser` extension.

## Requirements

- Use the desktop app or a remote worker that exposes the RenWork Browser.
- Keep `RenWork Browser` enabled in `Settings > Extensions`.

Then go back to the session view and ask RenWork to open a website.
