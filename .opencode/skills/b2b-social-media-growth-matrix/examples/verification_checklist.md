# 5-Point Post-Publish Verification Checklist

Before reporting completion of any social media publishing task, verify all 5 items:

1. **[ ] Visual Asset Inspection**:
   - For image posts: File is a 1200x1000 high-res infographic PNG without text clipping.
   - For PDF carousels: Document opens cleanly and page transitions render smoothly.

2. **[ ] Copywriting & Technical Precision**:
   - Supply voltage ranges, current parameters, and gain bandwidth specs match official datasheets.
   - 100% P2P pin-compatible cross-reference parts (e.g., LM358, AD820, SN65HVD3082) are accurate.
   - Relevant industry hashtags are attached.

3. **[ ] DOM Dropzone Attachment Confirmation**:
   - Image/document thumbnail preview was confirmed rendered inside the composer modal before submission.

4. **[ ] Dialog Dismissal & Backend Settle Time**:
   - Composer modal disappeared cleanly (`state='hidden'`) confirming database commit.

5. **[ ] Live Feed Screenshot Archiving**:
   - A full-screen live feed screenshot is captured and saved to the project directory with relative markdown link presented to user.
